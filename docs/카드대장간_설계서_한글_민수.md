# 앱인토스 6원소 카드 강화 포인트 게임 - 시스템 코드 구조 및 디렉토리 설계서

> **작성 기준:** 2026. 08. 25  
> **기반 기획:** 앱인토스 6원소 카드강화 포인트게임 기획서 v1.0  
> **기술 스택:** React + TypeScript + Granite (Client) / Node.js + NestJS (Server) / PostgreSQL + Redis (Database)

> **현재 저장소 참고:** 이 문서의 모노레포 구조는 최종 목표 구조입니다. 현재 실행 코드는 Granite React Native 단일 앱 구조이며, 먼저 구현된 회원 기능의 실제 파일·함수·API 계약은 [회원 기능 구조 설명서](USER_MEMBERSHIP_ARCHITECTURE.md)를 기준으로 사용합니다.

## 1. 전체 프로젝트 구조 개요

본 시스템은 **앱인토스 Granite (React Native) 기반 클라이언트**와 **NestJS 기반 백엔드 서버**, 그리고 공통 타입을 공유하는 **Monorepo / Shared Modules** 구조로 설계되었습니다.

- **클라이언트 (`apps/client`)**: 사용자 UI/UX rendering, Granite / TDS React Native 컴포넌트, React Native Animation (Reanimated) 연출, 앱인토스 보상형 광고 SDK 연동 담당
- **서버 (`apps/server`)**: 모든 확률 판정(강화/파괴/팩 개봉), PostgreSQL DB 트랜잭션, 토스 포인트 API 연동, 어뷰징 검증 담당
- **공통 (`shared`)**: Client와 Server 간 공유하는 DTO, Enum, TypeScript Interface 관리
