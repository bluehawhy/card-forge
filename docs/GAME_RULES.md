# 카드 대장간 게임 규칙

이 문서는 구현과 QA에서 사용하는 **게임 규칙의 단일 기준**이다. 기획서나 이미지와 수치가 다르면 이 문서를 우선하며, 수치 변경은 문서 버전과 서버 규칙 버전을 함께 갱신한다.

## 1. 기본 용어

- 현재 강화 단계: 카드에 표시된 `+0~+10`
- 목표 강화: 성공했을 때 도달할 단계
- 일반 실패: 카드와 현재 강화 단계가 유지되는 결과
- 파괴: 카드가 소멸되는 결과
- 강화의 결정: 강화 카드 판매 시 얻는 포인트 교환용 재화
- P: 토스 포인트 단위

## 2. 카드 규칙

- 카드 원소: 땅, 물, 바람, 불, 빛, 어둠
- 카드 등급: 노말, 매직, 레어, 슈퍼레어, 유니크, 레전더리
- 강화 범위: `+0~+10`
- 같은 강화 단계라면 카드 원소·등급과 관계없이 판매 결정량이 동일하다.
- 판매·분해·합성·파괴된 카드는 보유 목록에서 제거한다.
- 제거된 카드도 도감 획득 기록과 최고 강화 기록은 유지한다.

## 3. 강화 확률

| 목표 강화 | 성공 | 일반 실패 | 파괴 |
|---|---:|---:|---:|
| +1 | 100% | 0% | 0% |
| +2 | 100% | 0% | 0% |
| +3 | 90% | 10% | 0% |
| +4 | 75% | 25% | 0% |
| +5 | 60% | 30% | 10% |
| +6 | 50% | 35% | 15% |
| +7 | 40% | 40% | 20% |
| +8 | 35% | 40% | 25% |
| +9 | 30% | 40% | 30% |
| +10 | 25% | 40% | 35% |

### 판정 규칙

1. 서버가 요청 시점의 규칙 버전과 현재 단계를 확인한다.
2. 성공, 일반 실패, 파괴의 합은 항상 100%여야 한다.
3. 성공하면 현재 단계가 목표 강화 단계로 변경된다.
4. 일반 실패하면 현재 단계가 유지된다.
5. 파괴되면 카드가 소멸한다.
6. 모든 결과에서 강화 비용과 재료가 소모된다.
7. 과거 실패 횟수는 다음 시도의 확률에 영향을 주지 않는다.
8. 실패 누적 보정, 확정 성공, 천장 시스템은 없다.

## 4. 파괴 방지석

- 강화 실행 전에 사용 여부를 선택한다.
- 판정 결과가 파괴일 때만 효과가 발동한다.
- 발동하면 카드와 현재 강화 단계는 유지된다.
- 강화 비용, 강화 재료, 파괴 방지석은 소모된다.
- 성공률과 파괴 확률 자체를 변경하지 않는다.
- 파괴가 없는 `+1~+4` 강화에는 사용할 수 없다.

## 5. 카드 판매 보상

| 강화 단계 | 판매 결정 | 포인트 환산 가치 |
|---|---:|---:|
| +0 | 30개 | 0.01P |
| +1 | 60개 | 0.02P |
| +2 | 120개 | 0.04P |
| +3 | 300개 | 0.1P |
| +4 | 600개 | 0.2P |
| +5 | 1,200개 | 0.4P |
| +6 | 2,400개 | 0.8P |
| +7 | 4,500개 | 1.5P |
| +8 | 7,500개 | 2.5P |
| +9 | 15,000개 | 5P |
| +10 | 30,000개 | 10P |

### 판매 규칙

- 판매 확정 시 카드는 소멸하고 되돌릴 수 없다.
- 결정은 서버 거래 원장에 기록한 뒤 잔액에 반영한다.
- 카드 원소와 등급은 판매 결정량에 영향을 주지 않는다.
- +10 판매 후에도 도감의 +10 달성 기록은 유지한다.
- 판매 전 획득 결정과 판매 후 잔액을 화면에 표시한다.

## 6. 결정과 포인트 교환

- 교환 비율: **결정 3,000개 = 1P**
- 1회 교환량은 1P의 정수 배수만 허용한다.
- 결정 3,000개 미만 잔액은 교환할 수 없으며 계속 보유한다.
- 결정 보유 한도와 유효기간은 없다.
- 카드 판매 횟수에는 제한이 없다.
- 출시 초기 일일 교환 한도: **3P**
- 출시 초기 월간 교환 한도: **90P**
- 한도 초과 결정은 다음 날·다음 달로 이월한다.

### 교환 예시

- 결정 2,900개 보유 중 +3 카드 판매: 300개 획득
- 총 3,200개에서 1P 교환
- 결정 3,000개 차감
- 결정 200개 잔액 유지

+10 카드 한 장을 판매하면 결정 30,000개를 얻어 총 10P 가치가 생긴다. 일일 한도가 3P라면 `3P + 3P + 3P + 1P`로 최소 4일에 걸쳐 교환한다.

## 7. 카드팩과 광고

- 무료팩: 계정당 하루 1개
- 광고팩: 보상형 광고 완료 1회당 1개
- 광고팩 한도: 계정당 하루 10개
- 광고 로딩·재생·완료 검증 실패 시 이용 횟수를 차감하지 않는다.
- 같은 광고 완료 이벤트로 두 번 보상하지 않는다.
- 광고팩 10회 누적 시 레어 이상 카드 1장을 보장한다.
- 카드 발행 수량과 보유 수량에는 제한을 두지 않는다.
- 팩별 등급 확률은 출시 전 확정하고 개봉 전에 공개한다.

## 8. 중복 카드 처리

- 판매: 판매표에 따른 강화의 결정 지급
- 분해: 해당 원소 조각 지급
- 강화: 지정된 카드·원소 재료로 사용
- 합성: 동일 등급 카드 5장을 소모해 상위 등급 카드 획득 판정

분해량, 강화 비용, 합성 성공률과 팩 등급 확률은 아직 확정되지 않았다. 구현 전 별도 규칙 버전으로 확정해야 한다.

## 9. 서버 처리 순서

### 강화

1. `requestId` 중복 여부 확인
2. 사용자와 카드 소유권 확인
3. 카드 상태와 현재 단계 확인
4. 요청 규칙 버전과 비용 확인
5. 비용·재료 잠금 및 차감
6. 서버 난수로 결과 판정
7. 카드 상태와 도감 기록 변경
8. 강화 로그와 재화 원장 저장
9. 하나의 트랜잭션으로 확정
10. 클라이언트에 판정 결과 반환

### 판매

1. 카드 소유권과 판매 가능 상태 확인
2. 강화 단계별 결정량 확인
3. 카드 상태를 판매 완료로 변경
4. 결정 거래 원장 생성
5. 잔액 반영 후 결과 반환

### 포인트 교환

1. 결정 잔액 확인
2. 일일·월간 교환량 확인
3. 포인트 월렛 예산과 지급 가능 상태 확인
4. 결정 차감과 교환 요청 생성
5. 외부 지급 성공 시 완료 처리
6. 실패 시 중복 지급 없이 재시도 가능한 상태로 보관

## 10. 필수 UI 고지

강화 실행 전 다음 정보를 항상 표시한다.

- 목표 강화 단계
- 성공 확률
- 일반 실패 확률과 결과
- 파괴 확률과 결과
- 파괴 방지석 적용 여부
- 소모 비용과 재료
- 현재 판매 결정
- 성공 후 예상 판매 결정

판매·교환 전에는 취소 불가능 여부, 획득·차감량, 일·월 잔여 한도를 표시한다.

## 11. 미확정 항목

다음 항목은 임의 구현하지 않고 기획 확정 후 문서에 추가한다.

- 카드팩별 등급 획득 확률
- 등급별 강화 비용과 재료 수량
- 카드 분해 보상
- 합성 성공률과 실패 결과
- 파괴 시 검은 재 지급량
- 파괴 방지석 제작 비용과 획득량
- 일·월 포인트 한도 상향 조건의 실제 운영 수치

## 12. 정책 검토 조건

강화 결과가 결정 획득량에 영향을 주고 결정이 포인트로 교환되는 구조이므로, 출시 전에 앱인토스에 사전 검토를 요청한다. 허용되지 않으면 다음 예비 규칙으로 전환한다.

- 강화 카드는 아르카나 코인으로만 판매
- 카드와 게임 재화는 포인트로 직접 교환 불가
- 토스 포인트는 출석, 팩 개봉 수, 강화 시도 수, 판매 횟수 등 확정 활동 미션으로만 지급
- 강화 성공 여부와 카드 희귀도는 포인트 지급량에 영향을 주지 않음
