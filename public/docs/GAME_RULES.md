# 카드 대장간 게임 규칙 v2

> 규칙 버전: `card-forge-rules-v2`
> 상태: 구현 기준 확정 · 기존 서버 v1 로직은 별도 마이그레이션 필요

이 문서는 구현과 QA에서 사용하는 게임 규칙의 단일 기준이다. 기획서나 이미지와 수치가 다르면 이 문서를 우선하며, 확률과 보상을 변경할 때는 문서·서버 규칙 버전·변경 이력을 함께 갱신한다.

## 1. 핵심 순환

1. 보상형 광고를 완료하고 카드팩 1개를 연다.
2. 6원소·6등급 중 카드 1장을 얻는다.
3. 카드를 바로 보관하거나, 보상형 광고를 완료하고 강화를 시도한다.
4. 강화 성공 시 한 단계 상승한다. 실패 시 카드는 유지되지만 추가 강화가 영구 잠긴다.
5. 보관칸 5개가 모두 차면 보상형 광고를 완료해 5장 전체를 일괄 판매한다.
6. 등급·강화 단계·오늘의 원소 보너스로 계산한 결정을 받는다.
7. 결정 10,000개를 토스 포인트 1P로 교환한다.

유료 카드팩·유료 재화·캐시 결제는 제공하지 않는다. 수익 모델은 보상형 광고만 사용한다.

## 2. 카드

- 원소: 땅, 물, 바람, 불, 빛, 어둠
- 등급: 노말, 매직, 레어, 슈퍼레어, 유니크, 레전더리
- MVP 카드 수: `6원소 × 6등급 = 36장`
- 강화 단계: `1~10강`
- 카드 보관칸은 5개이며 카드가 5장 차면 추가 카드팩을 열 수 없다.
- 판매할 카드는 선택하지 않고 보관칸의 5장 전체를 판매한다.
- 강화할 카드는 보관 중인 카드 가운데 자유롭게 선택할 수 있다.
- 판매되거나 합성·분해된 카드는 보유 목록에서 제거한다.
- 제거된 카드도 도감 획득 기록과 최고 강화 기록은 유지한다.

## 3. 카드팩과 광고

- 계정당 카드팩 획득 기회는 하루 20회다.
- 카드팩 1회마다 보상형 광고 1회를 끝까지 완료해야 한다.
- 광고 완료 1건당 카드 1장만 지급한다.
- 광고 로딩·재생·완료 검증 실패 시 카드와 이용 횟수를 차감하지 않는다.
- 같은 광고 완료 이벤트와 `requestId`를 두 번 사용할 수 없다.
- 일일 횟수는 KST 00:00에 초기화한다.
- 별도 무료팩과 유료팩은 제공하지 않는다.
- 실제 카드 보관은 5개 보관칸으로 제한하고, 판매 후 보관칸을 다시 비운다.
- 등급별 획득 확률과 천장은 출시 전에 별도 규칙 버전으로 확정하고 팩 개봉 전에 공개한다.

## 4. 강화

### 4.1 기본 규칙

- 카드는 1강으로 발급되며 최대 10강까지 강화할 수 있다.
- 카드는 보관칸에 들어온 즉시 강화할 수 있다.
- 카드 1장만 보유한 상태에서도 강화할 수 있고, 5장을 모두 얻은 뒤 각각 강화할 수도 있다.
- 판매 광고를 시작하기 전까지 강화 순서와 시점은 사용자가 자유롭게 정한다.
- 강화 시도마다 보상형 광고 1회를 완료해야 한다.
- 광고 완료 후 서버가 규칙 버전과 현재 상태를 확인하고 난수를 판정한다.
- 성공하면 강화 단계가 1 상승한다.
- 실패하면 현재 단계와 카드는 유지되지만 추가 강화는 영구적으로 잠긴다.
- 카드 파괴, 파괴 방지석, 검은 재는 사용하지 않는다.
- 강화가 잠긴 카드도 현재 가치로 판매할 수 있다.
- 현금이나 유료 재화로 성공률을 높일 수 없다.

카드 상태는 다음과 같다.

| 상태 | 의미 |
|---|---|
| `ENHANCEABLE` | 강화 가능 |
| `ENHANCEMENT_LOCKED` | 강화 실패로 추가 강화 불가 |
| `MAX_LEVEL` | 10강 도달 |
| `SOLD` | 판매 완료 |

### 4.2 강화 확률

1강 카드가 10강에 도달할 누적 확률은 약 0.40%로 구성한다.

| 목표 단계 | 해당 시도 성공률 | 1강부터 누적 도달 확률 |
|---|---:|---:|
| 2강 | 100% | 100% |
| 3강 | 90% | 90% |
| 4강 | 80% | 72% |
| 5강 | 70% | 50.40% |
| 6강 | 60% | 30.24% |
| 7강 | 50% | 15.12% |
| 8강 | 40% | 6.05% |
| 9강 | 33.13% | 약 2.00% |
| 10강 | 20% | 약 0.40% |

강화 광고를 보여주기 전에 목표 단계, 성공률, 실패 시 강화 잠금, 현재 가치와 성공 후 가치를 표시한다.

## 5. 카드 가치

| 등급 | 1강 기본 가치 | 10강 기본 가치 |
|---|---:|---:|
| 노말 | 10,000결정 | 100,000결정 |
| 매직 | 20,000결정 | 200,000결정 |
| 레어 | 30,000결정 | 300,000결정 |
| 슈퍼레어 | 50,000결정 | 500,000결정 |
| 유니크 | 70,000결정 | 700,000결정 |
| 레전더리 | 100,000결정 | 1,000,000결정 |

카드 한 장의 판매 가치는 다음 공식으로 계산한다.

```text
등급별 1강 기본 가치 × 현재 강화 단계 × 오늘의 원소 배율
```

## 6. 오늘의 대장간 기후

서버가 게임 내 가상 기후를 확정한다.

| 대장간 기후 | 보너스 원소 |
|---|---|
| 맑음 | 빛 |
| 흐림 | 어둠 |
| 비 | 물 |
| 강풍 | 바람 |
| 폭염 | 불 |
| 황사 | 땅 |

- 기후 변경 주기는 24시간이다.
- 서버가 매일 KST 00:00에 오늘의 기후를 확정한다.
- 모든 사용자에게 같은 기후를 적용하며 하루 동안 변경하지 않는다.
- 6개 기후를 무작위로 섞은 주머니에서 하루에 하나씩 사용한다.
- 6일 동안 각 기후가 정확히 한 번 등장하고, 모두 사용하면 다시 섞는다.
- 결과와 규칙 버전을 서버에 저장하며 클라이언트가 기후를 결정하지 않는다.
- 실제 지역 날씨가 아닌 게임 내 가상 기후라고 UI에 표시한다.

오늘의 원소와 일치하는 카드의 1.5배 보너스는 **계정당 하루 첫 판매 1회**에만 적용한다.

- 첫 판매의 카드 5장 중 오늘의 원소와 일치하는 카드만 1.5배다.
- 첫 판매의 나머지 원소 카드는 1.0배다.
- 두 번째 판매부터 모든 카드는 1.0배다.
- 첫 판매 보너스를 사용하지 않아도 다음 날로 이월하지 않는다.
- 보너스 사용 여부는 KST 날짜와 함께 서버에 기록한다.

## 7. 카드 판매

- 카드 보관칸은 5개가 전부이며 5장이 모두 차야 판매할 수 있다.
- 판매 대상은 선택하지 않고 보관칸에 있는 5장 전체로 자동 확정한다.
- 사용자는 판매 광고를 시작하기 전까지 보관칸에서 강화할 카드만 자유롭게 선택할 수 있다.
- 판매 1회마다 보상형 광고 1회를 완료해야 한다.
- 광고 실패·중단 시 카드를 판매하거나 광고 이벤트를 소비하지 않는다.
- 판매 광고를 요청한 순간부터 완료·실패가 확정될 때까지 판매 버튼을 `광고 대기 중...` 상태로 표시하고 중복 입력을 막는다.
- `광고 대기 중...`에는 카드팩 개봉, 카드 강화, 판매 재요청과 보관칸 변경을 잠근다.
- 광고가 실패하거나 닫히면 잠금을 해제하고 같은 5장을 그대로 보존한다.
- 서버는 광고 완료, 카드 소유권, 판매 가능 상태, 중복 요청을 검증한다.
- 카드별 가치를 계산한 뒤 5장의 결정을 합산해 하나의 트랜잭션으로 지급한다.
- 판매 완료된 5장은 `SOLD` 상태가 되며 취소할 수 없다.
- 판매 전 보관칸 5장의 카드별 가치, 기후 보너스, 합계와 취소 불가 사실을 표시한다.

예를 들어 첫 판매에서 오늘의 기후가 비라면 물 카드만 1.5배이고 나머지 네 원소는 기본 가치다. 같은 날 두 번째 판매부터는 물 카드도 기본 가치다.

## 8. 결정과 토스 포인트

- 교환 비율: **결정 10,000개 = 토스 포인트 1P**
- 1P의 정수 배수만 교환한다.
- 10,000개 미만 잔액은 계속 이월한다.
- 결정 보유 한도와 유효기간은 없다.
- 게임 자체의 일일·월간 교환 한도는 두지 않는다.
- 실제 지급은 앱인토스 프로모션 승인, 회당 한도, 사용자 한도와 예산 범위 안에서만 처리한다.
- 외부 지급 성공 전 교환은 `PENDING`으로 관리한다.
- 지급 실패·타임아웃 시 결정을 이중 차감하거나 포인트를 중복 지급하지 않는다.

## 9. 광고량과 경제 기준

강화하지 않은 카드 5장을 판매하려면 카드팩 광고 5회와 판매 광고 1회, 총 6회가 필요하다. 하루 20장을 모두 획득해 네 묶음으로 판매하면 최소 24회의 광고가 발생한다.

현재 강화 확률로 사용자가 성공 또는 실패 잠금까지 계속 시도하면 카드 한 장당 강화 광고는 평균 약 4.66회다. 카드 5장 묶음은 카드팩·강화·판매를 합쳐 평균 약 29.3회의 광고가 발생한다.

출시 전 다음 기준으로 실제 데이터를 최소 2~4주 측정한다.

- 광고 채움률과 완료율
- 보상형 광고 실제 eCPM과 공제 후 정산금
- 등급별 팩 확률을 반영한 카드 1장당 기대 결정
- 사용자가 원소 보너스를 받는 실제 비율
- 결정 10,000개당 포인트 지급비
- 서버·DB·세금·CS·부정 이용 손실

보수적 시뮬레이션에서 운영비 공제 전 총 eCPM이 약 2,550원, 향후 앱인토스 수수료까지 포함하면 약 3,000원 아래로 내려갈 경우 손실 가능성이 있다. 실제 운영 기준은 콘솔 데이터로 재계산하며, 안정 목표 eCPM은 5,000원 이상으로 둔다. 이 값은 보장 단가가 아니라 출시 전 검증 가정이다.

## 10. 서버 처리 원칙

- 팩·강화·판매·결정·포인트 결과는 서버가 최종 확정한다.
- 광고 완료 이벤트와 `requestId`는 한 번만 사용할 수 있다.
- 카드 5장 판매, 결정 원장, 첫 판매 보너스 사용 처리는 하나의 DB 트랜잭션으로 확정한다.
- 규칙 변경 시 기존 카드에 적용할 버전과 신규 카드에 적용할 버전을 명시한다.
- 프로모션 예산 부족 시 신규 교환을 안전하게 중단한다.
- 매크로, 광고 조작, 다계정과 비정상 반복 요청은 지급을 보류하고 감사 로그를 남긴다.

## 11. 미확정 항목

- 카드팩 등급별 획득 확률과 천장
- 카드 합성 성공률과 실패 결과
- 카드 분해 기능과 원소 조각 사용처
- 강화 광고 외 추가 무료 재료 사용 여부
- 토스 게임 프로모션의 실제 지급 계약과 콘솔 승인 조건

미확정 값은 임의 구현하지 않는다.

## 12. v1에서 제거된 규칙

- `+0~+10`, 카드 파괴, 파괴 방지석, 검은 재
- 강화 실패 후 같은 카드 재도전
- 단계만으로 정하던 고정 판매 보상표
- 결정 3,000개당 1P
- 일 3P·월 90P 교환 한도
- 무료팩 하루 1개와 광고팩 하루 10개
- 단일 카드 판매

기존 서버의 위 로직은 v2 구현 단계에서 API·DB 마이그레이션과 함께 교체한다.
